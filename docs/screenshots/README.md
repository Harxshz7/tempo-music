# Tempo Screenshots

This directory contains visual captures of Tempo across mobile and desktop interfaces.

## Required Shots

| File | Description | State / Content |
|---|---|---|
| `login.png` | Login Screen | Server URL, Username, Password input fields, Connect button |
| `library.png` | Library Screen | Grid/List view of Albums, Artists, or Songs |
| `player_full.png` | Fullscreen Player | Cover artwork, track title, artist, seek bar, neo playback controls |
| `player_mini.png` | Mini Player Bar | Bottom-docked player bar above tab bar |
| `search.png` | Search Screen | Query input, search results cards |
| `settings.png` | Settings Screen | Server info, theme/audio settings toggle |

## Capturing Instructions

1. Run the app (`npm run web` or on device/emulator).
2. Connect to a Subsonic / Navidrome server instance with sample media.
3. Capture clean screenshots (1080x1920 or standard device resolution).
4. Save png images to this directory (`docs/screenshots/`).
